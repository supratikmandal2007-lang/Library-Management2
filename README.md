# Library Desk

Static library management app (HTML + CSS + JS). No server, no build step.
Features: books, members, issue/return, due dates, overdue fines (Rs 2/day), search, JSON backup.
Data is stored in the browser (localStorage).

## Publish on GitHub Pages
1. Create a new public repository.
2. Upload index.html, style.css, app.js, README.md to the repo root (unzipped).
3. Settings > Pages > Source: "Deploy from a branch" > main / (root) > Save.
4. Your permanent link: https://YOUR-USERNAME.github.io/REPO-NAME/
